# Arpège

Tablatures ukulélé à partir d'accords et d'un motif d'arpège, pour Android et Windows.

Les versions se téléchargent dans [Releases](https://github.com/chpoulain/Arpege/releases/latest) :

- `Arpege.apk` : Android
- `Arpege-*-Portable.exe` : Windows, sans installation

Une fois installée, l'application se met à jour d'elle-même depuis cette page.
